# Enderman Overhaul — Unique Endermen in Every Biome

Enderman Overhaul 9minecraft Mod reimagines the humble enderman as a whole family of biome-specific creatures. Instead of a single black silhouette, every biome now has its own enderman variant - each with a unique GeckoLib model, hand-drawn textures, glowing eyes, custom sounds and fluid animations that make the End's messengers feel at home wherever they wander.

## What this build is

An unofficial rebuild of **Alex Nijjar**, **AlexNijjar**, **Joosh**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.

## Source code
